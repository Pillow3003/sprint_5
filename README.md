# Проект автоматизированного тестирования — Sprint 5

Этот проект содержит автоматические тесты для проверки функциональности веб-приложения, разработанного в рамках спринта 5. Тесты реализованы на Python с использованием библиотеки Selenium WebDriver и организованы по различным модулям для удобства расширения и поддержки.

---

## Структура проекта

```plaintext
sprint_5/
├── locators/                      # Каталог с централизованными локаторами элементов
│   └── locators.py                # Определения локаторов для различных страниц
│
├── tests/                         # Каталог с файлами тестов
│   ├── test_announcement.py       # Тесты, связанные с размещением объявлений
│   └── test_user_registration.py  # Тесты регистрации и авторизации
│
├── .gitignore                     # Конфигурационный файл для исключения в git
├── conftest.py                    # Конфигурация pytest fixtures
├── data/                          # Данные, необходимые для тестов (тестовые данные)
├── helpers/                       # вспомогательные скрипты и утилиты
├── README.md                      # Этот файл
```
## Описание компонентов

### `locators/locators.py`
Централизованный файл локаторов элементов UI. Используется для избежания дублирования и повышения читаемости тестов. Реализованы локаторы для страниц объявлений, регистрации и т.д.

### `tests/`
Папка содержит разделённые по функциональности тестовые сценарии:
- `test_announcement.py` — тесты, связанные с созданием, редактированием и удалением объявлений.
- `test_user_registration.py` — тесты регистрации новых пользователей, логина и выхода.

### `conftest.py`
Файл для настройки фикстур pytest:
- Инициализация драйвера (Chrome)
- Конфигурация окружения перед запуском тестов
- Передача данных между тестами

### `data/`
Местоположение тестовых данных:
- Имя пользователя или другие параметры, которые могут отличаться при каждом запуске или быть статическими.

### `helpers/`
Вспомогательные функции и утилиты:
- Генерация тестовых данных (email)

---

## Важные требования к тестам

- Все тесты организованы в виде последовательных классов или функций, начинающихся с `test_`.
- Для регистрации используется динамическая генерация уникального email при каждом запуске.
- В каждом тесте обязательно присутствует `assert`, проверяющий результат (например, наличие сообщения или изменение статуса).
- В тестах отсутствуют `sleep`, заменённые на явные ожидания (`explicit waits`).
- В коде не должно быть закомментированного или неиспользуемого кода.
- Тесты выполняются независимо друг от друга и могут запускаться в любом порядке.

## Как запускать тесты

1. Запустите тесты командой:
```bash
pytest
```
Для подробного вывода используйте:
```bash
pytest -v
```
## Настройка и расширение
- Для добавления новых тестов создавайте новые файлы в папке tests/ по аналогии с существующими.
- Все локаторы, вспомогательные функции и фикстуры размещены в соответствующих папках.
- Постоянно обновляйте локаторы в locators/locators.py при изменениях в UI, чтобы тесты оставались актуальными.
## Рекомендации
- Перед запуском удостоверяйтесь, что всё окружение настроено правильно.
- Используйте фикстуры для инициализации и закрытия браузера.
- Для расширения функционала добавляйте новые сценарии, следуя существому стилю написания тестов.
- Документируйте новые тесты для поддержки и читаемости.
